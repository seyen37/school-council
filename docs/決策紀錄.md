# 校園議事廳・決策紀錄（ADR）

> 記錄本專案的關鍵決策與理由，供日後改動時查閱脈絡。每條含：決策、理由、影響。
> 決策流程採 QODA（Question → Options → Decision → Approval），標註「QODA」者為經用戶明確核准的選項。

## D1 沿用 emperor 架構，不從零重寫（QODA）
原專案（Joanna8521/emperor，MIT）已驗證可行：資料檔驅動的議會定義、BYOK 瀏覽器直連三家 API、streaming 逐一發言、史官總結。沿用可把工時全部投在校園領域內容上。
**影響**：技術棧固定為 Vite + React + framer-motion + marked，無後端；擴充方式與原作相同（加資料檔即加議會）。

## D2 定位「實務為主、帶點戲味」；玩家依入口任該方主席（QODA）
發言貼近真實校園行政生態（處室本位、教師權益、家長關切），保留人物個性與交鋒趣味，可兼作行政溝通演練工具。玩家在學校＝校長、教師會＝理事長、家長會＝會長，聯席會議三選一。
**影響**：persona 寫作準則＝「戲是包裝、乾貨是本體」，所有風格皆延續此原則。

## D3 委員會採「預設名單＋點名可勾選」，不採嚴格法規比例（QODA）
法定組成比例（教評會教師代表過半等）以「貼近慣例的預設名單」呈現，把彈性留給使用者，法規要點寫進會議 agenda 提示注入 prompt。
**影響**：`meetings[].defaultOn` 是慣例參考值，不是合規保證；嚴肅演練場景由「嚴謹公文」風格補強。

## D4 會議歸屬：教評會歸聯席、考核會歸學校、親師座談歸聯席
教評會依法含校長／家長會代表／教師代表→ 三方（聯席）；考核會僅校方＋教師代表→ 學校入口；親師座談是導師×家長→ 從家長會入口移到聯席（2026-07-15 依用戶指示調整）。
**影響**：入口的意義是「誰主持、誰是主體」，不是「誰出席」；跨方人員可出現在任一議會的角色池。

## D5 校務設定用 `requires` 條件驅動名單；班級規模分界為 23／24 班
小校（23 班以下）＝教導主任＋輔導教師編制；中大型（24 班以上）＝教務／學務／總務／輔導四處室。附幼與否決定幼兒園主任、幼教師代表、幼兒園家長代表是否出現。設定鈕為單鈕按下即切換。
**影響**：新增條件角色只要在角色上掛 `requires: { scale, kinder }`，所有名單與點名面板自動跟隨。

## D6 風格層（STYLE_DEFS）與角色層（persona）正交
語氣規範獨立成 STYLE_DEFS，每種風格四段：turn（正式發言）／ext（場外）／record（紀錄筆調）／regent（顧問裁示）。11 種風格 × 34 個角色不需改寫任何 persona。
**影響**：新增風格＝加一組範本；English 固定排最後；風格鈕固定兩行呈現。

## D7 會議層主席覆寫（meeting.chair）
`chairOf(council, profile, meeting)` 支援單一會議指定不同主席（首例：學年會議由「學年代表」主持，非校長）。主席角色自動從 AI 名單剔除。
**影響**：任何會議要換主持人，只要在會議定義加 `chair: { roleId, label }`。

## D8 頭像先用字牌，不生圖
Plaque 元件原生支援無圖時顯示單字字牌（faction 配色），視覺已足；日後要立繪只需把 PNG 放 public/avatars/ 並填 avatar 欄位。
**影響**：零圖片資產即可上線，體積小、載入快。

## D9 GitHub 上版流程照 personal-playbook：雙遠端＋用戶本人操作
repo 名 school-council（與 package 名一致）；origin＝seyen37、backup＝seyenbot（走既有 github-backup SSH alias）；所有登入、push 由用戶本人執行，AI 只產檔＋給步驟（playbook 原則 A）。
**影響**：repo 內建 init_github.ps1（一次性）、push.ps1、pull.ps1；.ps1 一律 UTF-8 with BOM。

## D10 致敬方式三件套
LICENSE 並列原作者著作權（Copyright (c) 2026 JWang (Joanna8521) ＋衍生作者）、README 專章「致敬原作」附原 repo 與 demo 連結並請訪客先給原作按星、首次 commit 訊息註明 "a tribute to Joanna8521/emperor"；另由用戶本人到原 repo 按星與留言。
**影響**：MIT 衍生作品的合規＋禮貌範本，日後衍生專案沿用。

## D11 Vercel 部署設定
Hobby 免費方案；GitHub App 僅授權 school-council 單一 repo（最小權限）；Vite preset 自動偵測、無環境變數（BYOK 純前端）；`school-council.vercel.app` 被佔用，接受 `school-council-one.vercel.app` 不另購網域。
**影響**：push main 即自動部署；帶 hash 的部署網址轉登入頁為 Vercel 預設保護，屬正常現象。

# 校園議事廳 🏫

**一所國小、三方勢力。你是主席，滿場 AI 與會者輪番發言、針鋒相對，會後自動留下一份可以帶走的會議紀錄。**

改寫自 [Joanna8521/emperor（百官朝議）](https://github.com/Joanna8521/emperor)（MIT License），把明代朝堂換成台灣國民小學的議事現場。

## 四個入口

- **學校行政**（你是校長）：處室主任、人事、會計、職工同仁與會。可開「主管會議」「行政會議」「學年會議」（此會由學年代表主持，各學年導師與科任代表與會）「考核委員會」。
- **教師會**（你是教師會理事長）：低中高年級導師代表、科任、行政教師代表與會。可開「理事會議」（理事推動會務、校內預先協調溝通）「理監事會議」（監事監督會務推展與經費收支）「會員代表大會」。
- **家長會**（你是家長會長）：副會長與各年段班級代表與會。可開「家長委員會」（各委員對口學校行政處室，提出支援與協調工作，可邀對口主任列席）「家長代表大會（家代會議）」「常務委員會」（緊急或重要行政事務）。
- **聯席會議**（主持身分可選校長／教師會理事長／家長會長）：三方派代表齊聚，內建十一種會議：校務會議、課發會、教評會、親師座談、學生獎懲委員會、常態編班委員會、性平會、學生申訴評議委員會、午餐委員會、輔導及特教推行委員會、畢業典禮籌備會。

## 校務設定

大門與「點名」面板皆可設定，名單會自動跟著變：

- **學校規模**：23 班以下（教導主任＋輔導教師的小校編制）／ 24 班以上（教務、學務、總務、輔導四處室編制）。
- **幼兒園**：附設（幼兒園主任、幼兒園教師代表與幼兒園家長代表加入名單）／未附設，按一下即切換。

## 特色機制

- **十一種會議風格**（大門與點名面板皆可切換，影響全場語氣與會議紀錄筆調）：實務帶戲味（預設）、嚴謹公文（引法規、簽呈筆調，適合行政演練）、鄉土劇（台味衝突拉滿）、議會質詢（連環逼問、壓力測試提案）、溫馨共好（非暴力溝通示範）、武俠（聚義廳議事，經費是銀兩、教育局是朝廷）、辦公室喜劇（偽紀錄片吐槽，笑點是糖衣、內容是真的）、宮鬥（御前議事、綿裡藏針，紀錄如起居注）、偵探推理（提案是案件、發言是證詞，紀錄寫成結案報告）、實況主播（直播腔開會、賽後精華戰報）、English（全場英文開會練英文）。

- **每種會議有預設出席名單**，貼近校園慣例（教評會教師代表過半、午餐委員會有營養師與家長代表），可在「點名」面板自行增減，並為每位與會者指派不同模型。
- **場外聲音**：里長、地方記者、熱心志工家長會在討論中途隨機插話關切，頻率可調可關。
- **壓軸總評**：督學（學校與聯席）、退休教師前輩（教師會）、榮譽會長（家長會）開啟後固定在紀錄落筆前出場。
- **會議紀錄**：會後自動產出 Markdown 會議紀錄：發言要點、爭點交鋒、決議與待辦，可一鍵複製。
- **請顧問裁示**：主席累了，交給退休老校長顧問代為總結拍板。
- **多模型混搭**：Anthropic（Claude）、OpenAI（GPT）、Google（Gemini），可設定預設供應商，也可為個別角色指派。
- **內建使用說明**：大門的「使用說明」按鈕點開即是完整操作指南（內容在 `src/guide.js`，Markdown 格式好維護）。
- **API key 只存在你的瀏覽器**（localStorage），直連各家官方 API，沒有任何伺服器。

## 本機執行

```bash
npm install
npm run dev
```

## 部署到 Vercel

1. 推上 GitHub。
2. 到 [vercel.com](https://vercel.com) 選 **Add New → Project** 匯入這個 repo。
3. Vercel 會自動偵測 Vite（build `vite build`、輸出 `dist`），按 **Deploy**。
4. 之後每次 push 自動重新部署。

## 費用

每位發言的與會者就是一次 API 呼叫。小會（常務委員會 3 人＋紀錄）約 4 次；大會（校務會議 15 人＋場外＋督學＋紀錄）可達 18 次上下。請在「點名」面板斟酌陣容。

## 增改角色與會議

- 角色 persona 全部在 [`src/councils/roles.js`](src/councils/roles.js)：複製一個現有角色、改寫 persona，設定 `faction`（配色）與 `requires`（依校務設定顯示）即可。
- 各議會與會議在 [`src/councils/school.js`](src/councils/school.js)、[`teachers.js`](src/councils/teachers.js)、[`parents.js`](src/councils/parents.js)、[`joint.js`](src/councils/joint.js)：把角色加進 `officials`（順序即發言順序），在 `meetings` 新增一種會議（`defaultOn` 是預設出席、`agenda` 會注入提示詞）。
- 介面文案與提示詞組裝在 [`src/councils/index.js`](src/councils/index.js)。

想幫角色加頭像：把 PNG 丟進 `public/avatars/`，在角色的 `avatar` 欄位填路徑（例如 `/avatars/zongwu.png`），字牌就會換成立繪。
